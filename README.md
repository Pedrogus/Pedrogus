## 🔌 Robótica e IoT

Gosto de trabalhar na ponte entre hardware e software: ler sensores no dispositivo, enviar os dados para uma API e transformar isso em informação útil para o usuário.

| Plataforma | O que faço com ela |
|---|---|
| **ESP32** | Leitura de sensores de temperatura e umidade e envio dos dados para o back-end |
| **Raspberry Pi** | Construção de um cyberdeck portátil rodando Arch Linux |

**Projetos de hardware**

-  **Monitor de adega (Vinheria Agnello)**: leitor de temperatura e umidade com ESP32, pensado para adegas de vinho. As leituras atualizam o status atual do vinho comprado dentro do sistema da Vinheria Agnello (autenticação JWT, DNS interno e pipeline CI/CD).
-  **Cyberdeck com Raspberry Pi**: computador portátil montado a partir de um kit, com Arch Linux instalado e configurado como ambiente de desenvolvimento e uso diário.

**Sinergia com meus projetos de software**: o simulador IoT do **AgroBot** (telemetria de estufa com alertas automáticos por severidade) segue a mesma lógica de leitura, classificação e alerta que aplico em hardware real.
